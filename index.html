01认知差异：宿主混音与现场混音

宿主混音与现场最大的差异，其实只有两个词：时间与容错率。理解了这两点，剩下的都是手法。

🎛 宿主混音

  • 时间：可反复修改、无限回放，允许慢慢打磨
  • 容错率：高——出错可撤销、重来，没人当场听见
  • 成品：对最终的录音负责

🔊 现场调音

  • 时间：实时一次成型，没有第二次机会
  • 容错率：低——出错全场听见，没得撤销
  • 成品：对整场演出的每个瞬间负责

我的做法 · 把现场当宿主混音

既然差异只在时间和容错率，那我的应对是：把每一场演出都当作在宿主里混音——不是靠临场感觉，而是尽量在演出前就把系统校准到位，让现场的混音手法和工作流跟宿主混音保持一致。

  • 系统提前校准、建立模板，让每次混音都在同一套基准上开始
  • 把「实时、不可撤销」的压力，转化成「提前就位、一次到位」的习惯
  • 工作流固定下来，现场只是执行，而不是即兴创作

02现场工作流 · 三种团队配置

从接到项目到撤场收工，团队规模不同，准备内容与当日流程完全不同。点击卡片查看完整流程。

1

工作流 1 · 小型演出

1 位调音师 · 无系统工程师 / 无舞台助理 / 无监听调音师
＋
  • 适用：小酒吧、小型 Livehouse、乐队拼盘
  • 特点：一人包办——系统、混音、监听、沟通全扛

▍接到项目后的准备

  1. 对接主办/艺人：确认演出时间、场地、乐手人数与设备清单
  2. 拿到舞台图（Stage Plot）与输入列表，提前规划通道分配
  3. 核对场地设备：调音台、音箱、话筒够不够，缺的提前沟通
  4. 备个人工具箱：备用线、备用话筒、转接头、胶布、记号笔；无线话筒备好电池、查好电量
  5. 确认返送需求：谁要地板返送、谁要 IEM

▍演出当日时间安排

12:00到场，勘察场地、确认电源与设备
13:00布台、走线、架鼓、放话筒
14:00系统检查：通电、逐通道送信号；无线话筒扫频、查电量、沿台走一圈试麦
15:00试音（每乐队 20–30 分钟）
18:00观众入场前检查，设好安全声压
19:00开场：混音 + 盯啸叫
22:00结束、撤场

▍工作顺序

  1. 先确认电源与安全（三相电、接地），再动设备
  2. 布台走线 → 系统通电 → 逐通道送信号确认
  3. 试音顺序：鼓 → 贝斯 → 吉他 → 键盘 → 人声 → 合练
  4. 演出中：优先盯啸叫与人声清晰度

▍无线设备检查与频率管理（小型）

  1. 检查流程：看接收机信号灯 → 换新电池 → 天线立起对准舞台 → 试麦沿舞台走动确认无死角
  2. 频率管理：接收机自动扫频选干净频点；多套无线之间错开（间隔 ≥ 400kHz）
  3. 把频点分配表贴到台子上，换人换麦一眼可查
  4. 兜底：备用电池 + 1 支有线话筒随时顶上
2

工作流 2 · 中小型演出

1 位调音师 + 2–3 位舞台助理
＋
  • 适用：中型 Livehouse、音乐节小舞台、企业活动
  • 特点：调音师一人兼顾 FOH 与 Monitor（返送），舞台交助理打理

▍接到项目后的准备

  1. 向主办要齐技术文件：舞台图、输入列表、时间表（Run Sheet）
  2. 给助理分好工：一人管话筒摆位、一人管线材设备、一人管艺人沟通
  3. 提前踩点：确认舞台尺寸、电源位置、吊挂点
  4. 备主备设备：备用话筒、备用 DI、备用线
  5. 无线频率规划：到场先扫描环境，多套无线错开频点、避开本地强信号
  6. 与艺人确认试音顺序，压缩试音时间

▍演出当日时间安排

08:00到场，勘察场地
09:00系统搭建：助理布台走线，调音师调系统
11:00系统调试（Smaart 或听感对齐）＋ 无线 RF 扫描与频点分配
12:00乐队 A 试音
13:00乐队 B 试音（助理间隙换话筒位置）
14:00全乐队合练彩排
16:00观众入场前最终检查（含无线复查）
17:00开场
21:00结束、撤场

▍工作顺序与分工

  1. 调音师一人兼顾 FOH 混音与返送（Monitor），舞台交给助理（摆位、换话筒、艺人沟通）
  2. 助理负责线检与通道确认，有问题及时报告
  3. 试音按乐队顺序流水进行，间隙做设备调整
  4. 演出中：助理盯舞台，调音师主扩与返送一起看、优先盯啸叫

▍一人兼顾 FOH + Monitor 的小技巧

  1. 返送先做 Ring Out（逐频点压啸叫），演出中返送基本不动
  2. 返送混音先存快照，乐手要调就改 Aux 发送，不碰主扩
  3. 优先用 IEM 减少返送啸叫风险，地板返送留作备用
  4. 用 Talkback 快速问乐手需求，别频繁下台

▍无线设备检查与频率管理（中小型）

  1. RF 扫描：用接收机扫描或协调软件（如 Shure Wireless Workbench）扫一遍现场频谱
  2. 频点分配：多套无线之间错开频点（间隔 ≥ 400kHz–1MHz），避开电视与本地强信号
  3. 检查清单：电池换新/满电、天线位置与朝向、接收机信号灯正常、备用机待命
  4. 演出中：盯接收机信号；断频先换频点或备用机，别慌着拔线
3

工作流 3 · 中大型演出

2 位调音师（FOH + Monitor）· 可能涉及录音与 OB
＋
  • 适用：大型音乐节、体育馆演唱会、卫视节目
  • 特点：分工明确，系统与网络音频是重头

▍接到项目后的准备

  1. 提前数周对接，收齐技术文件包（舞台图、通道表、Run Sheet）
  2. 明确分工：FOH 管主扩，Monitor 管返送/IEM，录音与 OB 单独输出
  3. 系统提前规划：线阵列吊挂、超低摆放、补声（fill）覆盖
  4. 网络音频规划：Dante / MADI 路由表，主备冗余
  5. 无线频率协调：多套无线话筒 + IEM 需专业 RF 协调，提前避开电视广播频段
  6. 与艺人团队确认监听需求：IEM 混音数量、个人返送内容

▍演出当日时间安排

06:00进场（货车到）
08:00舞台搭建完成，系统吊挂
10:00系统调试（Smaart 全系统对齐）＋ RF 无线协调确认
12:00FOH / Monitor 通道检查（含无线接收机状态）
13:00艺人试音（按 Run Sheet 时间）
16:00彩排 / 合练
18:00观众入场，静场检查
19:30开场
23:00结束，撤台 / 转场

▍工作顺序与重点

  1. FOH 与 Monitor 各自独立工作，通过对讲（comms）协作
  2. 录音 / OB 从 FOH 取 dry 信号，避免混响压缩污染
  3. 走网络音频时，先做路由表并备份场景文件
  4. 应急预案：主备调音台、主备网络、备用功放

▍无线频率协调（大型）

  1. 用专业工具做全系统协调：Shure Wireless Workbench / Sennheiser WSM
  2. 统筹考虑电视、广播、其他演出团队的频谱占用，预留间隔
  3. 硬件：天线分配器 + 指向性天线 + 天线放大器；话筒与 IEM 频段错开
  4. 设主备频率与自动切换（Spectrum Manager），断频自动跳备用
  5. 全程保留频率分配表，撤场前归档，方便下次复用

03七大学习方向与手段

每个方向列出要补的能力与对应手段，点击卡片可展开具体操作步骤。

1

声音系统方向

手段：Smaart 实测 + 跟一场系统搭建
＋
  • 线阵列 / 超低的覆盖与相位对齐
  • 系统链路定位：调音台 → 处理器 → 功放 → 音箱

▍怎么操作

  1. 用 Smaart 发粉噪，检查主扩与超低分频点的相位，用延时对齐
  2. 沿覆盖区走动监听，确认声压是否均匀，微调线阵角度
  3. 逐级送信号（台 → 处理器 → 功放 → 音箱），确认故障出在哪一级
  4. 把系统 EQ、延时、增益参数记成模板，下次直接复用
2

数字调音台方向

手段：吃透一台主流台 + 离线软件练快照
＋
  • 信号流路由、VCA/DCA、矩阵输出
  • 场景快照编程与网络音频

▍怎么操作

  1. 先装离线编辑软件，在家画路由、搭通道、做场景
  2. 建输入模板：鼓、贝斯、吉他、人声的通道链与编组一次做好
  3. 快照只存需要的范围（Recall Scope），换歌时不误动增益
  4. 用 VCA/DCA 分组控制鼓组、人声、乐队整体，减少慌乱
3

现场混音方向

手段：搭增益架构模板 + 减法混音
＋
  • Headroom 留 15–20dB，先砍后提
  • FOH 与 Monitor 的职责分工

▍怎么操作

  1. 先定增益：让乐手用演出音量弹奏，峰值留 15–20dB 余量再动 EQ
  2. 从「砍」开始：先做减法 EQ 清出频段，再考虑提升
  3. 人声优先：先把人声推到清晰，再往混音里塞乐器
  4. 建通道模板（EQ/压缩起始参数），每场微调而非重调
4

现场话筒方向

手段：跟场记录摆位 + 排查串音相位
＋
  • 鼓组 / 吉他箱 / 人声摆位要点
  • 啸叫压制：陷波、指向性控制

▍怎么操作

  1. 吉他箱用近距离动圈；鼓组注意踩镲串音，靠指向性避开
  2. 两只话筒拾同一声源时先查极性，避免低频抵消
  3. 啸叫先认频率 → 在返送/主扩对应通道拉陷波，或调整指向
  4. 养成摆位记录习惯，下次同乐队直接复用
5

监听系统方向

手段：从 Monitor 返送做起 + 练 IEM 混音
＋
  • 地板返送与 IEM 的取舍
  • 乐手个性化混音与听力保护

▍怎么操作

  1. 返送只给「乐手最需要的」：鼓手要 Click、主唱要自己
  2. IEM 混音做立体声，把乐器摆开，别全堆中间
  3. 监听增益宁低勿高，保护乐手听力
  4. 用 talkback 与乐手确认返送内容，快速调整
6

流程与协作方向

手段：跟老师傅跑场 + 总结 Soundcheck 清单
＋
  • Soundcheck 顺序与对讲沟通
  • 应急预案与故障快速定位

▍怎么操作

  1. 固定试音顺序：鼓 → 贝斯 → 吉他 → 键盘 → 人声 → 全乐队合练
  2. 先线检：每个通道送信号确认通断，再开始试音
  3. 备好备用话筒、备用线、备用通道
  4. 故障按链路逐级排查，先换最简单的（线、话筒）
7

数字音频网络方向

手段：用 Dante Controller 组网 + 打通 MADI / AES50 互转
＋
  • Dante：标准 IP 网络传多通道音频
  • MADI / AES50 / AVB 的适用场景

▍怎么操作

  1. 装 Dante Controller，看懂路由矩阵，做设备间订阅（subscribe）
  2. 配置主备冗余网络，主网断线自动切备、演出不中断
  3. MADI 用于调音台 ↔ 舞台接口箱；AES50 常见于 Behringer/Midas 生态
  4. 遇到混合设备现场，掌握协议转换（如 Dante ↔ MADI）

▍协议速查

协议特点典型场景怎么上手
Dante标准 IP 网络，千兆单线最多 512×512，自动发现数字台、舞台箱、个人监听Dante Controller + Virtual Soundcard
MADI点对点，同轴/光纤，64 通道，低延迟调音台 ↔ 舞台接口箱认光纤/同轴接线，配主备
AES50CAT5 单线 48 通道双向Behringer / Midas 生态X32 / M32 / Wing 互联

04核心重点 · 6 件事

现场最容易踩坑的地方，按优先级排序。

① 增益架构与 Headroom

现场必须预留 15–20dB 余量，防止乐手瞬间推大动态。

② 啸叫管理

听出啸叫前兆、快速用陷波器压住，是现场基本功。

③ 系统思维

从话筒到音箱全链路，任何一环出问题都要能定位。

④ 场景快照编程

每首歌、每个站位都可能需要不同快照，用场景管理提效。

⑤ 话筒摆位与串音

现场没有隔音棚，串音、相位是常态，摆位定成败。

⑥ 人声清晰度优先

现场观众最在意「听得清人声」，优先级与宿主混音不同。

05学习路线 · 三阶段

有前期功底可按自身节奏加速。

阶段 1 · 打基础

建立系统观（1–3 个月）

目标：看懂整个现场声音系统
  • 学系统调试（Smaart） + 吃透一台数字台
  • 掌握现场话筒摆位原则
阶段 2 · 上手

从 Monitor 做起（3–6 个月）

目标：独立完成一场演出的返送工作
  • 跟老师傅跑场、布台、走线
  • 练返送 / IEM 混音 + 啸叫处理
阶段 3 · 独立

独立 FOH（6–12 个月+）

目标：独立担任主扩调音师
  • 独立完成整场主扩混音，形成个人流程
  • 深入Dante / 大型系统 + 应急处理

  2. 到现场只学「这台子特有的」：按键布局与快捷操作
  3. 记录每台子的场景导出格式，方便跨台迁移

07实战故障排查手册

现场出问题不可怕，可怕的是慌。按「症状 → 可能原因 → 排查步骤」练习，点击卡片展开。

1

单通道无声

最常见 · 先换线再换口
＋
  • 症状：一个通道推上去没声，其他通道正常
  • 典型场景：某个话筒 / 乐器 DI 没信号

▍可能原因（按概率排序）

  1. 线缆断 / 插头松
  2. 通道被静音或增益在 0
  3. 接口（口）坏
  4. 话筒没电 / 没开 / 无线没配对
  5. 通道被路由到别处

▍排查步骤

  1. 看输入电平表：有信号 → 查路由/静音；无信号 → 查线
  2. 换线（最快验证法）
  3. 换接口试
  4. 查增益、静音、PFL
  5. 查话筒电源 / 无线状态
2

全场无声

先系统后通道 · 逐级送信号
＋
  • 症状：推任何通道都没声
  • 典型场景：刚通电 / 刚切场景后

▍可能原因

  1. 主输出 / 矩阵被静音或推子拉掉
  2. 处理器（DSP）没电 / 旁路
  3. 功放保护或没开
  4. 网络音频断线（Dante/MADI）
  5. 总线没接对

▍排查步骤

  1. 先看台子输出电平表：台子有输出 → 问题在台后
  2. 查主输出、矩阵、总线静音与推子
  3. 查处理器状态灯与旁路
  4. 查功放电源 / 保护灯
  5. 从台子送测试音逐级确认
3

嗡嗡声（电源哼声）

接地环路最常见
＋
  • 症状：持续的 50/100Hz 低频哼声
  • 典型场景：键盘 + 电脑 + 调音台共地

▍可能原因

  1. 接地环路（多台设备不同地）
  2. DI 地线未断开
  3. 信号线破皮 / 屏蔽层坏
  4. 电源质量差 / 三相电不平衡

▍排查步骤

  1. 逐个断开可疑设备，找到哼声来源
  2. 键盘/电脑加 DI 并切 Ground Lift
  3. 换信号线
  4. 把相关设备插到同一电源排插
4

持续啸叫

认频率 → 拉陷波 → 调指向
＋
  • 症状：特定频率持续啸叫
  • 典型场景：话筒正对返送 / 增益过高

▍可能原因

  1. 话筒指向返送音箱
  2. 返送 / 主扩增益过高
  3. 陷波器没拉到位
  4. 话筒类型选错（该用动圈用了电容）

▍排查步骤

  1. 先快速压返送增益止住啸叫
  2. 用 EQ 扫频认出啸叫频率
  3. 在该通道/返送拉陷波（Notch）
  4. 调整话筒指向与位置，避开返送
5

声音失真

推子不高也破 → 查前级
＋
  • 症状：推子不高但声音发破
  • 典型场景：乐手弹得很猛

▍可能原因

  1. 前置增益过高（输入削波）
  2. 处理器输入/输出过载
  3. 功放过载 / 限幅灯亮
  4. 喇叭拍边 / 单元损坏

▍排查步骤

  1. 看输入 PFL 电平：经常红 → 降增益
  2. 逐级看处理器与功放电平表
  3. 把增益架构重做：前级留 15–20dB 余量
  4. 仍破 → 换音箱/单元测试
6

声音断断续续

摇线找断点 · 重插所有口
＋
  • 症状：时有时无、沙沙声、接触不良
  • 典型场景：乐手走动踩到线

▍可能原因

  1. 线缆接触不良 / 焊点虚
  2. 插头松
  3. 无线话筒电池 / 天线问题
  4. 通道 Insert 有接触问题

▍排查步骤

  1. 边摇线边听，找到断点
  2. 重插所有接口，换备用线
  3. 查无线电池与天线
  4. 检查 Insert 是否插着无用设备
7

无线话筒断频

扫频分配 · 天线对准舞台
＋
  • 症状：频繁掉线、杂音、信号灯闪
  • 典型场景：音乐节多套无线同开

▍可能原因

  1. 频点冲突（多套无线）
  2. 天线位置 / 指向不对
  3. 电池电量低
  4. 现场其他射频干扰（手机、LED 屏）

▍排查步骤

  1. 用接收机自动扫频重新分配频点
  2. 天线对准舞台、远离金属与 LED
  3. 换电池
  4. 关掉附近多余射频设备
8

低频轰头 / 频段怪声

走动听覆盖 · Smaart 查相位
＋
  • 症状：某些座位低音过量或缺失
  • 典型场景：超低摆放不当

▍可能原因

  1. 超低与主扩相位未对齐
  2. 房间驻波（低频叠加/抵消）
  3. 覆盖不均（线阵角度不对）

▍排查步骤

  1. 在观众区走动听，标记问题区域
  2. 用 Smaart 查主扩 vs 超低相位，调延时
  3. 调整超低摆放 / 线阵角度
  4. 必要时加补声（Fill）
9

返送听不见

查 Aux 发送 → 查返送箱
＋
  • 症状：乐手说听不到自己 / 乐队
  • 典型场景：鼓手喊「没 Click」

▍可能原因

  1. 通道 Aux 发送没打开
  2. 返送推子 / 增益没到位
  3. 返送音箱故障 / 线坏
  4. 路由没接到返送输出口

▍排查步骤

  1. 看该通道Aux 发送量（PFL 确认）
  2. 查返送输出路由与推子
  3. 给返送送测试信号确认音箱
  4. 用 Talkback 和乐手确认
10

网络音频掉线

看状态灯 → 换线换口 → 查路由
＋
  • 症状：Dante / MADI 设备闪烁、通道消失
  • 典型场景：舞台接口箱频繁掉线

▍可能原因

  1. 网线 / 水晶头问题
  2. 交换机端口或环路
  3. 设备固件不匹配
  4. 主备切换失败

▍排查步骤

  1. 看设备状态灯（Sync / Link / Err）
  2. 换网线、换交换机端口
  3. 查 Dante Controller 的路由表与设备列表
  4. 先切备机，再重启故障设备
